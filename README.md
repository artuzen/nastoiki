# 🍸 Калькулятор настоек

Интерактивный калькулятор для расчёта партий настоек: когда закладывать, когда добавлять сливки/сироп, что купить и сколько это стоит.

**🌐 Открыть:** [artuzen.github.io/nastoiki](https://artuzen.github.io/nastoiki/)

---

## ✨ Что умеет

- 📋 **Заказ настоек** — выбор из списка, количество порций (по 0,5 л), дата готовности
- 🗓 **Автоматический расчёт партий** — дата закладки, дата добавки, дата готовности
- 🛒 **Список покупок** — ингредиенты по алфавиту, без нулевых строк
- 💰 **Цена заказа** — итоговая сумма и общая дата готовности
- 📥 **Экспорт в Excel** — выгрузка партий, покупок и цены
- 📋 **Копировать в буфер** — для вставки в Заметки на iPhone
- 💾 **Автосохранение** — заказ не теряется при закрытии браузера
- 📱 **Работает на iPhone как приложение**

---

## 📱 Установка на iPhone

1. Открой **Safari** → ссылку
2. Тапни **«Поделиться»** (квадрат со стрелкой вверх)
3. Выбери **«На экран "Домой"»**
4. Назови **«Настойки»** → **Добавить**
5. Иконка 🍸 появится на рабочем столе

---

## 🎯 Как пользоваться

### 1. Составить заказ

1. Выбери настойку из выпадающего списка
2. Укажи **количество порций** (1 порция = 0,5 л готовой)
3. (Опционально) поставь **дату готовности**
4. Нажми **«➕ Добавить в заказ»**
5. Повтори для всех настоек

### 2. Рассчитать

Нажми **«🔄 Рассчитать»** — появятся три таблицы:

- **🗓 Партии** — что и когда делать
- **🛒 Список покупок** — что купить
- **💰 Цена заказа** — во сколько обойдётся

### 3. Забрать результат

- **📋 Копировать** — копирует всё в буфер, вставляй в Заметки
- **📥 Скачать Excel** — сохраняет в `.xls` файл
- **🗑 Очистить заказ** — начать с нуля

---

## 🗓 Как считаются даты

**Основа:** 1 порция = 0,5 л готовой настойки. Все ингредиенты даны на 1 литр.

### Желаемая дата (общая для всех)

- Если в форме **указана дата** → берётся **самая поздняя** из всех
- Если **не указана** → считается **от сегодня**: `сегодня + срок самой долгой настойки + 2 дня`

### Дата закладки (одна на все партии)

Для каждой настойки считаем **свою** дату закладки:

```
закладка_i = желаемая − срок_i − 1
```

Берём **минимальную** из всех — это **общая дата закладки**.

### Дата добавки

Для каждой настойки задаётся индивидуально в рецепте (сколько дней от закладки до добавки сливок/сиропа).

### Дата готовности

```
готовность_i = закладка + срок_i
```

**«Заказ будет готов»** = самая поздняя из всех дат готовности.

## ⚠️ Важно знать

- **Заказ на iPhone ≠ заказ на компьютере.** Хранится в браузере каждого устройства отдельно, **не синхронизируется**.
- **Очистка истории Safari** удалит заказ. Просто добавь снова.
- **Обновление на iPhone:** потяни страницу вниз или открой иконку заново.
- **Обновление на компьютере:** `Ctrl+F5` (жёсткое обновление).
